# 产品体验问题清单

本文档记录从普通创作者视角实际操作 Minifeel 时遇到的问题，供多人持续补充和确认。记录事实、复现步骤与用户影响；未经复现的问题标为“待确认”。

## 记录规则

- 编号保持唯一，新增问题继续递增。
- 严重程度：`P0` 无法使用或数据损坏；`P1` 核心流程阻塞；`P2` 明显影响效率或理解；`P3` 轻微体验问题。
- 状态：`待处理`、`处理中`、`待验证`、`已处理`、`已解决`、`无法复现`；处理人写在状态后，例如 `已处理（lzzx）`、`已处理（zzf）`。
- 一条记录只描述一个问题；重复问题在备注中引用原编号。
- 修复后补充提交号和验证结果，不删除历史记录。

## 处理记录

- 处理人：`lzzx`。另一位协作者使用 `zzf` 标记，后续各自只更新本人完成的项目。
- BUG-001、BUG-002、BUG-007：开始创作后直接发送隐藏工作流指令，会话只显示用户原始创意；修复自动发送与发送按钮之间的竞态，中断后提供“重试”，已建立的项目作为可继续编辑的草稿保留。
- BUG-003、BUG-006：推理原文不再进入可见内容和无障碍树；移除路由离场过渡，页面切换时立即卸载旧画布。
- BUG-004、UX-003、UX-004、CHECK-002：同一用户消息产生的 Agent 模型循环使用同一创作批次，每轮最多收取一次文字模型费用；任务与积分流水按批次汇总，仍保留内部调用记录供排查。
- BUG-005：常见中止、连接关闭和 HTTP 状态错误转换为中文可操作提示。
- BUG-008、UX-010：根地址改为公开欢迎页；创意保存在当前浏览器会话中，未登录时进入独立登录页，成功后自动继续创建。
- UX-001、UX-002、UX-006：项目名限制为 16 字；首页展示四步创作路径；剧本要求记录自然时长，进入视频生成前按实时模型能力展示分段数量与预计积分并确认。
- UX-005、UX-008、UX-009：文本编辑增加“取消/保存”；画布资产面板增加拖入提示和复制成功反馈；无未保存错误时直接返回，由已有路由保存守卫处理失败情况。
- UX-007：资产增加角色名、造型版本、正选/备选、外观锚点和适用剧集/项目字段；重命名、移动和删除时同步元数据，画布资产面板显示角色与版本。
- BUG-009：移除文档面板的异步组件包装，确保组件 `ref` 始终暴露真实的 `flushSave`、`cancelSave` 和文档操作接口；Web 类型检查与生产构建通过。
- BUG-010：全局 401 处理在公开路由和路由尚未完成初始化时只清理登录状态，不抢先跳转；根路由恢复展示公开欢迎页，受保护路由继续由路由守卫拦截。
- BUG-011：欢迎页带入的首轮消息等待画布文件、节点列表和节点插件全部就绪后再自动发送，避免把空工具列表提交给 Agent。
- BUG-012：业务工具已经失败时不再请求或渲染交互组件，保留工具原始失败状态与结果；本地历史对话中 `HTTP 503` 正常显示，未再出现“工具界面加载失败”。
- 管理员供应商页面增加文本、图片和视频模型调试入口；本地实际验证 DeepSeek 文本与 BananaPro 单参考图图片返回，普通用户访问返回 403，Agnes 按用户要求未调用。
- BUG-013：确认本地代码已按 60 秒间隔串行调用 Agnes；最小 4 秒、720P、9:16 的 Flash 请求仍返回 HTTP 503，节点状态为 `failed` 且无输出。三次调用均未自动重试或启动后续分段，等待共享密钥没有并发任务且满足调用间隔后单次复测。
- UX-011：工作流说明补充图片生成后的自动入库位置与手动命名/分组入口；节点操作统一显示“保存到我的资产”。
- 验证：Server、Web、文本节点类型检查通过；Server、Web 和全部节点生产构建通过；本地根地址实际显示公开欢迎页、单一创意输入框和“开始创作”按钮；图片节点显示“保存到我的资产”；切换文档与画布后返回首页成功，无保存错误弹窗；失败视频工具保留 `HTTP 503`，不再附加渲染器错误。
